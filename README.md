# Academic Mathematics Portfolio - Erasmus+ 🇷🇴

This repository contains a collection of academic projects, assignments, and algorithms developed during my Mathematics degree, including coursework completed during my Erasmus+ exchange year in Romania.

### 📚 About This Repository
The purpose of this repository is to showcase my progression and practical application of mathematical concepts throughout my university studies. Studying abroad allowed me to adapt to a different educational system and tackle complex mathematical problems in a fully English-speaking academic environment.

### 🗂️ Structure
Here is an overview of the key subjects and projects included in this repository:

- **/Cryptography:** Implementation of cryptographic algorithms and data encryption techniques. This coursework provided a strong mathematical foundation for data security and digital assets.
- **/Graph-Theory:** Mathematical modeling of networks, node relationships, and graph algorithms. These concepts are directly applicable to complex data structures and AI network analysis.
- **/Object-Oriented-Programming:** Software design and implementation using OOP principles. This section demonstrates my ability to write clean, scalable, and modular code.

### 💡 Key Takeaways
These projects helped me build a strong foundation in logical problem-solving, algorithmic thinking, and translating pure mathematical theory into functional code.
